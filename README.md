# Ferramentas internas CIN

Pequenas ferramentas web de ficheiro único, feitas para o dia a dia da gestão comercial na CIN (Corporação Industrial do Norte).
Não têm backend nem instalação: basta abrir o `.html` no browser.

| Ferramenta | Ficheiro | O que faz |
|---|---|---|
| **Matriz de Risco de Cliente** | [`matriz-risco.html`](matriz-risco.html) | Avalia e classifica o risco comercial de clientes |
| **Reparações e Garantias** | [`garantias.html`](garantias.html) | Regista e acompanha pedidos de reparação e garantia de equipamentos |

## Dados

Os dados ficam guardados **localmente no browser** de quem usa a ferramenta. Este repositório não contém dados de clientes, e o `.gitignore` bloqueia exportações (`.json`, `.csv`, `.xlsx`).

> Repositório privado: uso interno.
